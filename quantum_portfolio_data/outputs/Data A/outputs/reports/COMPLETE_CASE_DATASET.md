# Exploratory complete-case HOSE dataset

- Period: `2020-01-01` to `2025-12-31`
- Retained: **394 tickers / 565,471 rows**
- Excluded relevant tickers: **51**
- Minimum observations: **40**

- Maximum unexplained calendar gap: **5 sessions**

This dataset is suitable for an exploratory end-to-end run. It is not a replacement for a verified point-in-time, corporate-action-adjusted, full-HOSE research panel. See `complete_case_exclusions.csv` and the limitations in `outputs/raw/manifest.json`.
